# Feature Specification: セ・リーグ順位推移グラフ

**Feature Branch**: `001-cl-standings-graph`  
**Created**: 2026-02-10  
**Status**: Draft  
**Input**: User description: "日本のプロ野球、セ・リーグの順位推移を表す折れ線グラフを作成するアプリを作ってください。アプリには、年度と開始月、終了月を指定できるようにしてください。何も指定されなかった場合は、アプリを起動した年のペナントレース開始時から現在までの推移のグラフを作成、年度のみが指定されたときは、その年の全ての推移のグラフを作成、年と開始月が指定された場合は、その年の開始月からシーズン終了までの推移のグラフを作成、年と開始月、終了月が指定された場合には、その期間の推移のグラフを作成してください。また、推移グラフで使用する折れ線グラフの線の色は、球団のカラーを用いてください。"

## Clarifications

### Session 2026-02-10

- Q: グラフをどのような形式で出力・表示しますか？ → A: インタラクティブなWebページ（ブラウザで表示）
- Q: X軸の時間粒度はどうしますか？ → A: 日単位（毎日の順位を表示）
- Q: 同順位の球団が複数ある場合、グラフ上でどのように表示しますか？ → A: 同じY座標に重ねて表示（線が重なる）
- Q: データの更新頻度とタイミングはどうしますか？ → A: リアルタイム（ユーザーアクセス時に毎回取得）
- Q: グラフにどのようなインタラクティブ機能を実装しますか？ → A: ホバーでツールチップ表示 + 凡例クリックで表示/非表示

## User Scenarios & Testing *(mandatory)*

### User Story 1 - デフォルト期間での順位推移表示 (Priority: P1)

ユーザーがアプリを起動すると、パラメータ指定なしで現在年のペナントレース開始（3月下旬）から現在日までのセ・リーグ全6球団の順位推移が折れ線グラフで表示される。各球団の線は球団カラーで描画される。

**Why this priority**: これが最も基本的な使用ケースであり、ユーザーが最も頻繁に使用する機能。パラメータ指定なしで即座に有用な情報を提供できることがMVPの価値。

**Independent Test**: アプリを起動し、パラメータを指定せずに実行することで、現在年のシーズン開始から現在までの順位推移グラフが表示されることを確認できる。

**Acceptance Scenarios**:

1. **Given** 現在が2026年5月15日である、**When** ユーザーがパラメータなしでアプリを起動する、**Then** 2026年3月下旬から5月15日までのセ・リーグ6球団の順位推移グラフが表示される
2. **Given** グラフが表示されている、**When** ユーザーがグラフを確認する、**Then** 各球団の線が球団カラー（巨人：オレンジ、阪神：黄色、中日：ドラゴンズブルー、広島：赤、DeNA：紫、ヤクルト：緑）で描画されている
3. **Given** グラフが表示されている、**When** ユーザーがY軸を確認する、**Then** 順位が1位から6位まで表示されている（Y軸は逆順：上が1位、下が6位）
4. **Given** グラフが表示されている、**When** ユーザーがX軸を確認する、**Then** 日単位で時系列が表示されている

---

### User Story 2 - 特定年度の全期間順位推移表示 (Priority: P2)

ユーザーが年度を指定すると、その年のペナントレース全期間（開幕から日本シリーズ前まで）の順位推移グラフが表示される。

**Why this priority**: 過去のシーズンを振り返る際に必要な機能。特定年度の全体像を把握できることで、歴史的な分析や比較が可能になる。

**Independent Test**: 年度パラメータ（例：2025）を指定してアプリを実行し、2025年シーズン全体の順位推移グラフが表示されることを確認できる。

**Acceptance Scenarios**:

1. **Given** ユーザーが年度「2025」を指定する、**When** アプリを実行する、**Then** 2025年3月下旬から10月上旬までの順位推移グラフが表示される
2. **Given** 過去年度のグラフが表示されている、**When** ユーザーがグラフを確認する、**Then** シーズン終了時の最終順位が明確に確認できる
3. **Given** 未来の年度を指定した、**When** アプリを実行する、**Then** エラーメッセージ「指定された年度のデータは存在しません」が表示される

---

### User Story 3 - 特定期間の順位推移表示 (Priority: P3)

ユーザーが年度と開始月、または年度・開始月・終了月を指定すると、その期間の順位推移グラフが表示される。

**Why this priority**: より詳細な分析を行いたいユーザー向けの機能。特定の期間（例：夏場の戦い、終盤戦など）に焦点を当てた分析が可能になる。

**Independent Test**: 年度と開始月（例：2025年7月）を指定してアプリを実行し、2025年7月からシーズン終了までの順位推移グラフが表示されることを確認できる。また、年度・開始月・終了月（例：2025年7月〜9月）を指定して、その期間のグラフが表示されることを確認できる。

**Acceptance Scenarios**:

1. **Given** ユーザーが年度「2025」と開始月「7」を指定する、**When** アプリを実行する、**Then** 2025年7月1日からシーズン終了までの順位推移グラフが表示される
2. **Given** ユーザーが年度「2025」、開始月「7」、終了月「9」を指定する、**When** アプリを実行する、**Then** 2025年7月1日から9月30日までの順位推移グラフが表示される
3. **Given** 開始月が終了月より後の日付を指定した、**When** アプリを実行する、**Then** エラーメッセージ「開始月は終了月より前である必要があります」が表示される
4. **Given** シーズン外の月（例：1月、2月、11月、12月）を指定した、**When** アプリを実行する、**Then** エラーメッセージ「指定された月はシーズン期間外です」が表示される

---

### Edge Cases

- 指定された年度のデータが存在しない場合はどうなるか？
- シーズン開始前や終了後の日付を指定した場合はどうなるか？
- 開始月が終了月より後の場合はどうなるか？
- 月の指定が1〜12の範囲外の場合はどうなるか？
- データ取得に失敗した場合（ネットワークエラーなど）はどうなるか？

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは、パラメータ指定なしで起動された場合、現在年のペナントレース開始日から現在日までの期間を自動的に設定しなければならない
- **FR-002**: システムは、年度パラメータのみが指定された場合、その年のペナントレース全期間（開幕から日本シリーズ前まで）を期間として設定しなければならない
- **FR-003**: システムは、年度と開始月が指定された場合、その年の指定月1日からシーズン終了までを期間として設定しなければならない
- **FR-004**: システムは、年度・開始月・終了月が指定された場合、その年の開始月1日から終了月末日までを期間として設定しなければならない
- **FR-005**: システムは、セ・リーグ6球団（読売ジャイアンツ、阪神タイガース、中日ドラゴンズ、広島東洋カープ、横浜DeNAベイスターズ、東京ヤクルトスワローズ）の順位推移データを取得しなければならない
- **FR-006**: システムは、各球団の折れ線を球団カラーで描画しなければならない（巨人：オレンジ、阪神：黄色、中日：ドラゴンズブルー、広島：赤、DeNA：紫、ヤクルト：緑）
- **FR-014**: システムは、インタラクティブなWebページとしてグラフを表示しなければならない
- **FR-015**: システムは、URLクエリパラメータまたはWebフォームでパラメータ指定を受け付けなければならない
- **FR-016**: システムは、同順位の球団が複数ある場合、同じY座標に折れ線を重ねて表示しなければならない
- **FR-017**: システムは、折れ線上にマウスをホバーした際、ツールチップで球団名・日付・順位・勝敗数を表示しなければならない
- **FR-019**: システムは、凡例の球団名をクリックすることで、その球団の折れ線の表示/非表示を切り替えられるようにしなければならない
- **FR-018**: システムは、ユーザーがアクセスする度にリアルタイムで最新の順位データを取得しなければならない
- **FR-007**: システムは、Y軸に順位（1位〜6位）を表示し、上が1位、下が6位となるように逆順で配置しなければならない
- **FR-008**: システムは、X軸に日単位の時系列（日付）を表示しなければならない
- **FR-009**: システムは、グラフに凡例を表示し、各線がどの球団を表すか識別できるようにしなければならない
- **FR-010**: システムは、無効なパラメータが指定された場合、適切なエラーメッセージを表示しなければならない
- **FR-011**: システムは、Webスクレイピングによりセ・リーグの順位データを取得しなければならない（NPB公式サイトまたは信頼できるスポーツ情報サイトから）
- **FR-012**: システムは、スクレイピング対象サイトの利用規約を遵守しなければならない
- **FR-013**: システムは、スクレイピングに失敗した場合、適切なエラーメッセージを表示しなければならない

### Key Entities

- **球団（Team）**: セ・リーグに所属する6球団。属性：球団名、球団カラー（RGB値またはカラーコード）、略称
- **順位データ（StandingsData）**: 特定日時における球団の順位情報。属性：日付、球団、順位（1〜6）、勝数、敗数、引分数、勝率、ゲーム差
- **期間設定（PeriodSettings）**: グラフ表示の対象期間。属性：年度、開始日、終了日
- **グラフ（Graph）**: 順位推移を視覚化した折れ線グラフ。属性：タイトル、X軸ラベル、Y軸ラベル、データ系列（各球団の折れ線）、凡例

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: ユーザーは、パラメータ指定なしでアプリを起動してから5秒以内に現在シーズンの最新順位推移グラフを確認できる（データ取得時間を含む）
- **SC-002**: ユーザーは、グラフを見て各球団の順位推移を一目で理解できる（球団カラーと凡例により識別可能）
- **SC-003**: ユーザーは、過去5年分の任意の年度の順位推移グラフを表示できる
- **SC-004**: ユーザーは、任意の月範囲を指定して、その期間の順位推移グラフを表示できる
- **SC-005**: システムは、無効なパラメータが指定された場合、100%の確率で適切なエラーメッセージを表示する
- **SC-006**: グラフは、視覚的に明確で、順位の変動が容易に追跡できる（線の交差が明確、色の区別が容易）
- **SC-007**: ユーザーは、凡例クリックにより特定球団のみを表示して、その球団の推移に焦点を当てることができる

## Assumptions

- ペナントレースの標準的な開始時期は3月下旬（3月20日頃）とする
- ペナントレースの標準的な終了時期は10月上旬（10月10日頃）とする
- データはユーザーアクセス時にリアルタイムで取得される
- グラフはインタラクティブなWebページとしてブラウザで表示される
- パラメータはURLクエリパラメータまたはWebフォームで指定可能
- ユーザーは日本語を理解できることを想定
- 球団カラーは指定された色を使用：巨人（オレンジ）、阪神（黄色）、中日（ドラゴンズブルー）、広島（赤）、DeNA（紫）、ヤクルト（緑）
